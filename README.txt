AUXILIO MECÁNICO 24HS - Web para GitHub Pages

ARCHIVO PRINCIPAL:
index.html

SUBIR A GITHUB PAGES:
1. Creá un repositorio en GitHub.
2. Subí index.html.
3. Entrá en Settings > Pages.
4. En Build and deployment elegí Deploy from a branch.
5. Seleccioná la rama principal (normalmente main) y /root.
6. Guardá y GitHub te dará la dirección de la página.
